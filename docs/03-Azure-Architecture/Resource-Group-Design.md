# Resource Group Design

## Resource Group

rg-clouddesk-prod

## Purpose

The Resource Group acts as the logical container for all Azure resources used by the CloudDesk Commerce Platform.

## Resources

- AKS
- ACR
- Application Gateway
- Azure Key Vault
- Azure Cache for Redis
- Azure Monitor
- Log Analytics Workspace
- Application Insights

## Benefits

- Easy management
- Simplified billing
- RBAC management
- Resource organization
